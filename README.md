# Personal Finance API

## Overview
A REST API built with Java and Spring Boot for tracking personal finances. Tool for providing tracking and visibility for spending habits.

## Features
- User management
- Transactions
- Categories
- Budgets
- Spending analytics
- JWT authentication
- Docker deployment


This API should be able to allow users to create an account that stores:
- Username
- Password
- Email Address

Users will be able to:
- Add transactions
- Change transaction categories
- Delete transactions
- View monthly spending
- View yearly spending
- Get forecasted spending per month
- Get forecasted spending per year

## Tech Stack
- Java 21
- Spring Boot
- PostgreSQL
- Maven

## Future Improvements
- Forecasted budget
- Predicted budget
