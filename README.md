# Personal Finance API

A REST API built with Java and Spring Boot for tracking personal finances.

## Tech Stack

- Java 21
- Spring Boot
- PostgreSQL
- Maven

## Planned Features

- User management
- Transactions
- Categories
- Budgets
- Spending analytics
- JWT authentication
- Docker deployment

## Functionality

This API should be able to allow users to create an account that stores:
- Username
- Password
- Email Address

Users will be able to:
- Add transactions
- Change transaction categories
- Delete transactions
- View monthly spending
- View yearly spending
- Get forecasted spending per month
- Get forecasted spending per year

## Backend

The data will include:
User
- Username
- Password
- Email Address

Transaction
- Transaction category
- Product name
- Price
- Time of transaction
- Location of transaction

Transaction Category
- Rent
- Groceries
- Subscriptions
- Leisure
- Gas
